# Daily Shadowing

初学者向けの短い日常英語を、6段階で練習するPWAです。

## MVPで実装済み

- 6段階学習: 聞く → 意味確認 → 音読 → オーバーラッピング → 文字ありシャドーイング → 文字なしシャドーイング
- 0.75 / 0.90 / 1.00 / 1.10倍のお手本読み上げ（端末TTS）
- マイク録音・録音再生
- Transformers.js + Whisper Tiny English によるブラウザ内音声認識
- WebGPU優先、利用できない場合はWASMへフォールバック
- 100点の学習用スコア
  - 単語一致 70%
  - スピード 15%
  - 流暢さ（長い間の少なさ）15%
- 認識結果と抜け・置換・余分な単語の表示
- 認識で失敗した単語を「苦手」に保存
- 教材中の語句を「知らなかった / 苦手 / 覚えた」で保存
- マイ単語帳
- 練習回数・ベストスコア・進捗をlocalStorageに保存
- PWA / Service Worker

## 教材

`data/lessons.json` を編集するだけで追加できます。初期版は30フレーズです。

- 朝のひとこと 10
- 家での会話 10
- かんたん雑談 10

文章は初学者向けに短く、日常でそのまま使いやすい表現を中心にしています。

## 起動

GitHub PagesなどHTTPS環境で `shadowing-app/` を開いてください。マイク機能とService WorkerはHTTPS（localhostを除く）が必要です。

初回採点時はWhisperモデルとTransformers.js関連ファイルのダウンロードが発生します。モデルはブラウザ側のキャッシュを利用します。

## 採点について

この点数は発音学の専門的な診断ではありません。Whisperの認識結果、正解英文との単語一致、発話速度、長い無音区間を組み合わせた「伝わりやすさ・練習用」の指標です。
